# Target: sdd-init scaffolds the ephemeral-archive gitignore for new projects

## Current statement

A fresh project bootstrapped with `sdd:init` creates the ephemeral `archive/`
directories but writes no `.gitignore` entries for them — so a new SDD project
tracks and pushes every archived artifact, the exact behavior SPEC-wf-035
removed from this repo. `sdd:init` must scaffold (append to or create) the
project's `.gitignore` with the five ephemeral archive paths, and SPEC-wf-035's
acceptance criteria must be sharpened to cover new-project scaffolding — the
criteria were written repo-inward, which is why the close-domain maiden-voyage
audit (blind test, 2026-07-03) could not find this hole from the invariant
alone.
