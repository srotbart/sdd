# Gap: session-start orphan check treats a missing archived reference as an error, not "unverifiable"

**Location:** `plugin/skills/session-start/SKILL.md:249`

**Reasoning:** The orphaned-work-item check flags a `gap-id` absent from the active-or-archive gaps directory as an error (`⚠ ... cannot be found`), but with local-only archives (SPEC-wf-035) a missing reference on a fresh clone or worktree with an empty cache is expected and must be reported as "unverifiable (archive is local-only)", not as an error.
